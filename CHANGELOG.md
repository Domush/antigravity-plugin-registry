# Changelog

All notable changes to `agy-plugin-registry` will be documented in this file.

## [1.0.1] - 2026-11-27

### Added
- **Expanded Plugin Discovery:** Added `antigravity-plugin` alongside `agy-plugin` across automated repository discovery, tag filtering, Issue-Ops submission validation, web portal copy, and author documentation.

## [1.0.0] - 2026-11-27

### Added
- **Automated Registry & Security Pipeline:** Scheduled and Issue-Ops GitHub plugin discovery, deterministic tree hashing, multi-layer static and AST security auditing, Ed25519 catalog signing, and GitHub Pages web portal publishing.
